# SQL Task: Pandemic Data Analysis

## Task Description
This task involves working with pandemic-related infectious disease data in MySQL. The task consists of 5 main steps:

1. **Data Loading**: Create pandemic schema, import data using Import wizard
2. **Normalization**: Normalize the infectious_cases table to 3NF
3. **Data Analysis**: Calculate statistics for Number_rabies by Entity and Code
4. **Date Calculations**: Create date difference columns using SQL functions
5. **Custom Function**: Build a function to calculate year differences or disease rates

## Folder Structure
- `results/` - Contains screenshots and output files for each step
- `sql_queries.txt` - Documentation of all SQL commands executed

## Database
- MySQL database
- Schema: pandemic
- Main table: infectious_cases
